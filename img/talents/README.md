# Icônes de talents

Dépose ici les icônes de talents : PNG, WebP ou JPEG, carrées de préférence.

- Nom de fichier sans accent ni espace : `brise_glace.png`, `orbe_feu.png`.
- Elles paraissent seules dans le menu **Logo** d'un talent, famille « Dossier talents »,
  une à deux minutes après l'envoi (le temps que le site se republie), en rechargeant la page.
- Le nom affiché vient du fichier : `brise_glace.png` devient « Brise glace ».
- Pour un talent élémentaire, un fichier en `_feu`, `_gel` ou `_foudre` suit l'élément du
  Mystique, comme les autres logos.

L'autre dossier d'icônes marche de même : `img/equipement`, pour tout ce que range l'Armurerie.
